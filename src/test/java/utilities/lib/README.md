# Framework Libraries

This directory contains JAR files used by the ExaAPI framework:

## PostgreSQL JDBC Driver
- **File**: postgresql-42.7.3.jar
- **Purpose**: Database connectivity for PostgreSQL
- **Version**: 42.7.3
- **Usage**: Used by PostgresUtil and DatabaseHelper classes

## Usage
The JAR files in this directory are referenced as system dependencies in pom.xml and are included in the classpath during test execution.
